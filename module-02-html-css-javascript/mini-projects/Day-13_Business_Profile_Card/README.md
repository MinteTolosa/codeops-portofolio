# Bole Brew Café Profile Card

A one-page styled profile card for **Bole Brew Café**, a fictional café located in Bole, Addis Ababa.

## Files

- `index.html` — page structure and content
- `styles.css` — all visual styling

## CSS Techniques Used

- CSS custom properties with `:root`
- Reusable spacing scale with `var()`
- Global `box-sizing: border-box`
- Google Fonts using the Inter typeface
- CSS box model with padding, border, margin, and border-radius
- Centered responsive card
- Typographic hierarchy using font size and weight
- Generous line-height for readability
- HSL color values
- Button `:hover` state changing only HSL lightness
- `:focus-visible` for keyboard accessibility
- `::before` pseudo-element for a decorative card accent
- No inline styles
- No IDs used for styling
