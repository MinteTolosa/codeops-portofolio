# Tip Calculator Script (ETB)

A fundamental JavaScript assignment that calculates tiered tips and local service fees (TeleBirr / CBE Birr) for restaurant bills.

## Requirements
* **Node.js** installed on your local machine.
* A terminal or command prompt interface.

## Setup and Installation
1. Clone or download this project folder to your computer.
2. Open your terminal and navigate to the project directory.

## How to Run the Script
Execute the script using the Node.js runtime with the following command:
```bash
node tip.js
```

## Features Demonstrated
* Data type conversion using `Number()`.
* Tiered tip calculation using `if...else` logic.
* Payment provider service fee processing using `switch` statements.
* Output formatting via JavaScript Template Literals.
