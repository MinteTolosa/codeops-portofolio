Requirements

---The project must:

Export withVat from pricing.js
Export format from pricing.js
Import both functions into summary.js
Store sample order data in orders.js
Use reduce() to calculate each order's item total
Destructure { price, qty } inside the item calculation
Use map() to create a new array of orders
Use the spread operator (...) to attach a total field
Use filter() to find orders over 500 ETB
Use reduce() to calculate the grand total
Format prices in ETB
Print a readable order summary


---Tip

Build the chain one method at a time and console.log() after each step.

Confirm that the shape of your data is what you expect before adding the next link.

---For example:

console.log(orders);

---Then:

console.log(ordersWithTotals);

----Then:

console.log(ordersOver500);

----Finally:

console.log(grandTotal);

---This makes it easier to identify errors before the chain becomes complicated.
