***Birr Watch
A simple web application to monitor and convert the Ethiopian Birr (ETB) against other global currencies.

***What it does

- Converts an entered amount of ETB into a selected foreign currency.
- Displays live exchange rate calculations.
- Allows users to add and manage specific currencies in a personal watchlist.

***API used

ExchangeRate-API (or your chosen provider) to fetch live currency conversion rates relative to ETB.

***How to run 

1 - Clone or download this project folder to your computer.
2 - Ensure your folder contains index.html, styles.css, and script.js.
3 - Open the index.html file in any modern web browser.

***Self-check 

Make sure you have an active internet connection to load the live rates.
Open your browser's developer console (F12) to verify there are no network errors if the dropdown menu fails to populate.
