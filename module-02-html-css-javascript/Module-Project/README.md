Project Title: Birr Budget

What it does:
Birr Budget is a simple personal budget app for people in Addis Ababa. It helps users record their income and expenses in Ethiopian Birr (ETB) and quickly see how much money they have left.

Feature list

- Add income
- Add expenses
- View total income
- View total expenses
- View remaining balance
- Search/filter transactions
- Save data in localStorage so it stays after refreshing
- Responsive design for phone and desktop
