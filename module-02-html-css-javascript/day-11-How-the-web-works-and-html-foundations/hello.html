Exercises

3. Lists: Build an unordered list of three Ethiopian products and an ordered list of two checkout steps.

4. Links: Add a relative link to a second page and an absolute link to an external site, wrapped in a < nav >.

5. Inspect: Open a real Ethiopian website, press F12, and find one header, < nav >, and < footer >. Note what you see./p
